## 2026-05-09 - XSS and Auth Hardening
**Vulnerability:** The web dashboard was vulnerable to stored XSS via user-controlled data (Discord usernames, fruit names, suspension reasons) being rendered directly into HTML templates. Additionally, the Basic Auth check was susceptible to timing attacks.
**Learning:** Python's `str.format()` does not perform recursive substitution. While literal curly braces in the template string must be escaped as `{{` and `}}`, values passed into the placeholders during the `.format()` call do NOT need brace escaping. Attempting to escape braces in the input values (e.g., `input.replace('{', '{{')`) results in visual regressions where the user sees literal double braces in the UI.
**Prevention:** Always use `html.escape()` for user-controlled data in HTML templates. Use `secrets.compare_digest()` for credential comparisons. Avoid shadowing the `html` standard library module by naming local HTML string variables `response_html` or similar.
