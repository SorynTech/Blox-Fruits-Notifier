## 2025-05-15 - N+1 Query in Server-Side Rendering
**Learning:** Iteratively querying the database for related records (e.g., getting rolls for every user in a dashboard) causes significant latency as the user base grows.
**Action:** Use cached columns for frequently accessed data or utilize SQL JOINs to fetch related records in a single round-trip.
